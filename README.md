# Cartoonification using GAN (CycleGAN)

## Description
This project converts real-world images into cartoon-style images using CycleGAN.

## Features
- Unpaired image-to-image translation
- High-quality cartoon outputs
- Preserves structure and style

## Dataset
- FFHQ: https://github.com/NVlabs/ffhq-dataset
- CartoonSet: https://google.github.io/cartoonset/

## How to Run
pip install -r requirements.txt  
python inference/test.py
